Arquivos oficiais Google Fonts, subsets para a frase. Cada diretório preserva OFL.txt e SOURCE.txt com URL exata do arquivo e licença. Fontes locais com preload somente da opção selecionada e font-display swap; nenhuma chamada ao Google Fonts durante uso do site. Não se espera a fonte para iniciar a abertura.

Fontes novas obtidas do CSS oficial [Google Fonts](https://fonts.googleapis.com/css2?family=Archivo+Black&family=Bebas+Neue&family=Bungee&display=swap&text=O%20MELHOR%20DA%20CIDADE). Origens/licenças: [Bebas Neue](https://github.com/google/fonts/tree/main/ofl/bebasneue), [Archivo Black](https://github.com/google/fonts/tree/main/ofl/archivoblack), [Bungee](https://github.com/google/fonts/tree/main/ofl/bungee). Anton já existia no projeto com a mesma documentação.

As quatro rotas usam generateStaticParams, lista permitida e notFound para entradas inválidas, com noindex/nofollow. Não há persistência da escolha. Famílias mais largas têm tamanho óptico ajustado para manter a frase completa no celular. QA1366 e320 em todas confirmou família, frase completa, mesma animação, texto dentro da viewport, saída automática e console sem erros.
